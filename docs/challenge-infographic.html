Pivot
Discovered Anthropic's API had no free tier — switched the entire AI backend to Google Gemini in a single session, with zero architecture rewrite, because the system was designed around a data contract, not a vendor.
Debug
A PDF-parsing library worked perfectly locally, then crashed in production. Root-caused it via real Vercel runtime logs to a missing native dependency — and fixed it correctly, not just worked around it.
Security
An API key was briefly exposed in a config file. GitHub's push protection caught it. The response — revoke, rotate, clean git history, verify — was executed completely and correctly.

Sixty days of building the skill. Nine days of proving it. One live product to show for it.
